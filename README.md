# pkinative-mcp

Model Context Protocol (MCP) server for PKI on the zero-dependency
[pkinative](https://github.com/Nizoka/pkinative) engine: inspect and verify
X.509 certificates, CSRs, CRLs, OCSP responses, CMS SignedData and RFC 3161
time-stamps; build and validate certificate chains; create certificates, CSRs,
CMS signatures, OCSP and time-stamp requests; open PKCS#8 and PKCS#12 without
ever returning a key byte; decode ASN.1, PEM and OIDs. No network, ever.

Third server of the "native" family after
[pdfnative-mcp](https://github.com/Nizoka/pdfnative-mcp) and
[zipnative-mcp](https://github.com/Nizoka/zipnative-mcp).
